# Portfolio UI & Design System

## Purpose
Define the design system, hero typography, interactive tech stack dock, and glassmorphic user interface architecture for Senior Angular Developer Kazi Ataul Goni's portfolio.

## Requirements

### Requirement: Hero Section Presentation
The hero section SHALL communicate senior frontend engineering leadership in Angular, Hamburg location, and current role at HaCon / Siemens.

#### Scenario: User visits the hero section
- **WHEN** a visitor loads the portfolio homepage
- **THEN** the headline "Kazi Ataul Goni" and subtitle "Senior Angular Developer" with the "⚡ Angular Expert" badge are visibly rendered with high-contrast obsidian glass styling.

### Requirement: Interactive Tech Stack Dock
The hero section SHALL feature an interactive glassmorphic tech stack dock showcasing core technologies.

#### Scenario: Hovering tech pills
- **WHEN** a user hovers over any tech pill (Angular 21, TypeScript, JavaScript, RxJS & NgRx, HTML5, CSS3, Docker · DevOps, Three.js WebGL)
- **THEN** the pill elevates smoothly with brand-specific neon glow and highlighted border.

### Requirement: CV Download Capability
The website SHALL allow direct one-click download of the verified official PDF CV.

#### Scenario: User clicks Download CV
- **WHEN** the visitor clicks the "Download CV" action button
- **THEN** the official PDF "Kazi_Ataul_Goni_CV.pdf" is downloaded immediately in a new tab without navigation interruption.
